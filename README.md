# Azure FinOps & Automated Cost Governance

An enterprise-style Cloud Financial Operations platform for Azure that
connects cloud expenditure to engineering accountability.

## Business problem

Unexpected cloud spending, underutilized Kubernetes workloads,
unallocated resources and insufficient cost ownership.

## Objectives

- Allocate cloud costs by project, environment, team and service.
- Monitor actual and forecasted spend against budgets.
- Detect cost anomalies and idle resources.
- Recommend Kubernetes CPU and memory rightsizing.
- Automate approved nonproduction shutdowns and cleanup.
- Publish monthly cost reports and cost-per-request metrics.

## Technology stack

Azure Cost Management, Azure Storage, Terraform, Azure Kubernetes
Service, OpenCost, Python, Pandas, Grafana, GitHub Actions and Azure OIDC.

## Governance principles

Read-only discovery by default, dry-run remediation, explicit approval,
least-privilege access, audit logging and post-action verification.

## Evidence

Actual Azure cost exports, baseline-versus-optimized comparisons,
automated tests, dashboard screenshots and documented measured or
simulated savings.

## Project status

Implementation in progress. Results will be marked complete only
after the corresponding tests and evidence have been captured.
